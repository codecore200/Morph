# Morph

p5.js 기반 2D 플랫포머 게임. 플레이어는 원·삼각형·사각형 도형으로 모핑하며 각 도형의 질량과 형태 차이를 활용해 스테이지의 장애물과 퍼즐을 통과한다.

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행된다. (정적 페이지, 별도 빌드 불필요)

## 구성

- `index.html` — 진입점, p5.js 및 스크립트 로드
- `style.css` — 전체 레이아웃 스타일
- `js/config.js` — 화면 크기·물리 상수·기믹별 매직 넘버 모음
- `js/utils.js` — 공용 유틸 함수
- `js/player.js` — 플레이어(모핑 도형) 상태·물리·충돌 처리
- `js/interaction.js` — 입력 처리
- `js/stage1.js`, `js/stage2.js` — 스테이지별 지형·기믹·진행 로직
- `js/hud.js` — 화면 상단 HUD
- `js/clearfail.js` — 클리어/실패 화면
- `js/screen.js` — 타이틀·스테이지 선택 등 화면 전환
- `js/sound.js` — 사운드 처리
- `js/main.js` — p5.js 진입 함수(setup/draw) 및 전체 흐름 제어
- `assets/` — 이미지 등 리소스

## 스테이지

- **Stage 1**: 상자·버튼·문 퍼즐로 세 도형을 익힌 뒤, 가시 구덩이·상자 디딤돌·풍선 관문을 지나 사이드스크롤 피날레(빠른 원만 거슬러 통과하는 역방향 컨베이어 벨트 → 무거운 사각형으로 내리찍어 뚫는 균열 바닥)로 이어지는 종합 활용 구간. 피날레 기믹은 Stage 2와 겹치지 않는 Stage 1 고유 요소
- **Stage 2**: 경사·풍선·문 퍼즐 → 점프 패드·무너지는 발판·좌우 왕복 이동 발판의 입체 클라이맥스 → 무게 다리(가벼운 원만 통과)·펜듈럼 해머·상승 기류(가벼운 도형이 높이 솟아 골인)로 이어지는 사이드스크롤 확장 피날레
